工具一：ClaudeCodeExtension

  • 一句话介绍：为 Visual Studio（.NET）提供统一 AI 编码 Agent 界面的扩展，把 Claude Code、Codex、Cursor Agent、Open Code、Devin 等 CLI/Agent 的输出收敛到一个可视化面板里。
  • 分类：编程插件 / Vibe Coding
  • 适合谁：在 Visual Studio 里主力开发 .NET / C#，同时又同时使用多个编码 Agent 的工程师与团队。
  • 典型场景：在 VS 内直接向 Claude Code 或 Codex 下达任务，AI 结束后自动查看 diff、贴截图/文件报错、追溯历史会话并核对用量。
  • 核心功能：图片与文件粘贴；Diff 查看器；AI 结束工作后可触发动作；用量统计；会话历史（依据仓库 description，其余能力资料未展开）。
  • GitHub Stars：资料未确认（本次 API 返回内容在该仓库处被截断，未包含 stargazers_count 字段）
  • 近期新增 Stars：资料未确认
  • 最近更新时间：资料未确认（该仓库出现在 pushed:>2026-10-06 的搜索结果中，可确认 10-06 之后有代码推送）
  • 最新版本：资料未确认
  • 开源协议：资料未确认
  • 支持平台：Visual Studio（.NET）；对接的 Agent 按描述包括 Claude Code、Codex、Cursor Agent、Open Code、Devin、PI、Antigravity、Reasonix
  • 使用成本：扩展自身成本资料未确认；底层各 Agent 需各自的订阅或 API 费用
  • 上手步骤：1）打开仓库确认许可证与 Release 包；2）按仓库说明从 Visual Studio 扩展市场或手动安装；3）在设置中配置已安装的 Agent CLI 路径与凭证；4）先在一个低风险小项目跑一次完整任务，确认 diff 展示与"任务结束动作"行为符合预期；5）再接入主力仓库。
  • 推荐理由：它解决的是一个真实存在的摩擦点——多 Agent 并用后，diff 审阅、用量统计、会话历史散落在不同终端里，切换成本高。把这一层收进 IDE 是提效方向明确的做法。
  • 局限与风险：Stars、协议、更新时间、版本均无法从本批资料确认，属于信息不完整的候选，接入前必须自行核验；仅支持 Visual Studio，VS Code / JetBrains 用户不适用；同时托管多个 Agent 的凭证会扩大密钥暴露面，需先确认它如何存储 API Key。
  • 官网/仓库链接：https://github.com/dliedke/ClaudeCodeExtension

工具三：GitHub Copilot 自定义指令 / 自定义 Agent / MCP 工作流（官方指南）

  • 一句话介绍：GitHub 官方给出的"如何让 Copilot 真正读懂你的代码库"的落地方法——在仓库中写入自定义指令与 Skills、配置自定义 Agent、并接入 Playwright 等 MCP 服务器。
  • 分类：效率工具 / Vibe Coding 工作流
  • 适合谁：已经在用 Copilot，但经常抱怨它"不了解本项目规范、答非所问"的个人开发者与团队。

  • 核心功能：仓库级自定义指令；可复用 Skills；自定义 Agent；MCP 服务器接入（文中以 Playwright 为例）。
  • GitHub Stars：不适用（GitHub 官方产品能力与官方文档，非独立开源仓库）
  • 近期新增 Stars：不适用
  • 最近更新时间：官方指南发布于 2026-10-12（GitHub Blog）
  • 最新版本：资料未确认
  • 开源协议：不适用（受 GitHub / Copilot 服务条款约束）
  • 支持平台：GitHub Copilot；具体客户端与 IDE 支持范围资料未确认
  • 使用成本：需 GitHub Copilot 订阅，订阅档位与价格资料未确认
  • 上手步骤：1）在仓库中新增自定义指令文件，写清技术栈、命名规范、禁止事项；2）把高频复用提示拆成 Skills；3）为固定流程定义职责单一的自定义 Agent；4）先接入 Playwright MCP 并在低风险仓库验证；5）每季度复核指令是否随代码演进过期。
  • 推荐理由：零额外采购、当天即可落地，而且把"个人提示词经验"沉淀为仓库内可版本化、可被全队复用的资产。这是本期成本最低、最可执行的一项。
  • 局限与风险：效果强依赖指令撰写质量，写得含糊反而误导模型；指令与 Skills 会随代码演进过期，需要维护责任人；接入 MCP 会扩大工具调用权限，应限定其可访问的资源范围。
  • 官网/仓库链接：https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-how-to-teach-copilot-about-your-codebase/
