事件二：Anthropic 向 METR 开放员工级访问，第三方评估从黑盒走向深访问

  • 发生了什么：Anthropic 于 10 月 15 日称，为评估系统安全，正向非营利评估机构 METR 的一个团队提供类似员工的访问权限，并与 Hugging Face 等多家机构进行早期讨论。
  • 技术变化：外部评估者不再只通过 API 或公开接口做黑盒测试，而是获得更深层的系统访问；具体权限边界、日志和隔离机制未披露。
  • 为什么重要：前沿模型安全评估正从“自评”转向“第三方深访问”，可验证性提高，但也会扩大攻击面与保密风险。
  • 产业影响：可能形成“评估访问权”的行业规范；Hugging Face 等平台若参与，角色将从模型托管扩展到独立评估基础设施。
  • 接下来关注：METR 是否发布报告、访问范围如何隔离、其他实验室是否跟进、Hugging Face 是否正式参与。
  • 来源/时间：Anthropic｜2026-10-15｜https://www.anthropic.com/news/an-update-on-independent-evaluators

事件三：Anthropic 称非法蒸馏率下降 90%+，模型防复制进入攻防阶段

  • 发生了什么：Anthropic 于 10 月 12 日发文称，通过防蒸馏措施将非法蒸馏发生率降低超过 90%。
  • 技术变化：具体防御技术未披露；目标是阻止开发者通过模型输出复制前沿能力，而不是传统版权内容复制。
  • 为什么重要：模型能力被“低成本复制”是前沿实验室的核心商业风险；防御升级可能改变 API 开放策略、开发者条款和访问控制。
  • 产业影响：模型指纹、水印、行为检测、访问分级和法律追责可能成为下一阶段标配；依赖蒸馏的小模型厂商成本上升。
  • 接下来关注：防御是否可复现、是否误伤合法微调、是否影响开发者生态与 API 价格。
  • 来源/时间：Anthropic｜2026-10-12｜https://www.anthropic.com/news/distillation-defenses
