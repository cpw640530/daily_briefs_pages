  • 核心功能：版本漂移检测、依赖审计、CLI 使用、面向 AI Agent 工具链的配置检查。

工具二：cc-thingz

  • 一句话介绍：面向 Claude Code、Codex CLI、Copilot、Cursor、Grok 和 Pi 等工具的可移植 skills、Agent、hooks 与扩展集合。
  • 分类：编程插件 / Vibe Coding / 自动化
  • 适合谁：需要在多个 AI 编程 Agent 之间复用工作流、代码审查规则和自动化钩子的开发者。
  • 典型场景：把代码审查、Git hooks、Agent skills 和命令配置统一迁移到不同 AI 编程工具。
  • 核心功能：跨工具 Agent skills、hooks、扩展、代码审查工作流，以及面向 Claude Code 和 Codex CLI 的插件能力。
  • GitHub Stars：35
  • 近期新增 Stars：资料未确认
  • 最近更新时间：2026-09-14，GitHub API 显示 updated_at 为 19:02:10 UTC，pushed_at 为 19:02:04 UTC。
  • 最新版本：资料未确认
  • 开源协议：MIT
  • 支持平台：Claude Code、Codex CLI、GitHub Copilot、Cursor、Grok、Pi Coding Agent 等；具体系统要求资料未确认。
  • 使用成本：开源免费；所接入的 AI 服务可能产生订阅或 API 费用。
  • 上手步骤：克隆仓库；根据 README 选择需要的 skills、Agent 或 hooks；复制到对应工具的配置目录；在测试项目中执行代码审查或自动化任务。
  • 推荐理由：适合已经使用多个 AI 编程工具的开发者，能够减少重复编写配置和工作流的成本。
  • 局限与风险：项目规模和社区仍较小，Stars 为 35；不同 Agent 的配置格式和权限模型可能存在差异；安装 hooks 或自动化命令前应审查脚本内容。
  • 官网/仓库链接：GitHub 仓库

工具三：ai-setup-sync

  • 一句话介绍：用于把 AI 编程工具配置文件和 MCP 配置从 GitHub 仓库同步到多个项目的 VS Code 扩展。
  • 分类：编程插件 / Vibe Coding / 知识管理
  • 适合谁：需要在多个代码仓库、成员设备或团队项目中统一维护 Claude Code、Copilot、Cursor、Codex 等 AI 配置的开发者和团队。
  • 典型场景：统一下发项目级 AI 指令、MCP 配置、Agent 规则和代码工作流设置。
  • 核心功能：从 GitHub 仓库同步 AI setup 文件；跨项目分发配置；支持 Claude Code、Copilot、Cursor、Codex、Antigravity 等工具。

  • 最新版本：资料未确认
  • 开源协议：资料未确认
