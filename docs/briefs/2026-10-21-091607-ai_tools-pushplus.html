  • 适合谁：希望在 iPad、iPhone 或 Android 设备上本地跑 agent、写代码、预览网页、远程 SSH/VNC 的开发者与创作者。
  • 典型场景：在 iPad 上临时改代码、跑脚本、预览本地网页；通过 BYOK 调用云端模型；连接远程开发机；用本地模型处理离线任务。
  • 核心功能：设备端 AI agent 工作区；Linux 环境；代码执行；本地 Web 预览；支持本地模型；BYOK 云 AI；Notes、Office、创意工具；远程桌面/SSH/VNC；iPad-first。

工具二：ui-annotate

  • 一句话介绍：浏览器扩展，把网页 UI 元素点击注释直接反馈给编码 agent，自动提供 selector、组件和 file:line。
  • 分类：Vibe Coding / 开发者工具 / 浏览器插件
  • 适合谁：使用 Claude Code、Codex、Cursor 做前端或全栈 Vibe Coding 的开发者。
  • 典型场景：在浏览器中点选按钮、表单或布局元素，直接告诉 agent 要改哪里；把视觉反馈转成精确代码定位，减少截图和文字描述。
  • 核心功能：点击元素；提取 selector、组件与 file:line；通过 MCP 和 hooks 连接 Claude Code、Codex、Cursor；把浏览器视觉上下文交给编码 agent。

  • 最新版本：资料未确认
  • 开源协议：资料未确认
  • 支持平台：浏览器扩展；具体浏览器范围资料未确认
  • 使用成本：资料未确认
  • 上手步骤：从 GitHub 仓库获取并安装扩展；在 Claude Code、Codex 或 Cursor 中配置 MCP/hooks；打开本地开发页面，点击元素并写注释；让 agent 读取注释并修改对应组件。
  • 推荐理由：直接解决 Vibe Coding 中“说不清 UI 位置”的痛点，把浏览器视觉反馈转成代码定位；与主流编码 agent 集成，工作流价值明确。作为近期活跃的新项目补充入选。

工具三：GitHub Copilot app 会话续接（VS Code）

  • 一句话介绍：把 GitHub Copilot app 中的 agent 会话迁移到 VS Code，保留对话、代码变更和工作上下文。

5. 今日选择建议

  • 编程场景：前端 UI 改动优先用 ui-annotate 点选元素，把 selector、组件和 file:line 交给 Claude Code/Codex/Cursor；移动或远程开发用 floe-agent；Copilot 用户用会话续接回 VS Code 继续任务。
  • 办公场景：floe-agent 适合在 iPad/手机上做笔记、文档、远程 SSH 和轻量自动化；Copilot 会话续接可减少跨设备上下文切换。
  • 创作场景：floe-agent 的 Notes、创意工具和本地预览适合移动创作；ui-annotate 适合网页视觉调整时快速向 agent 描述具体元素。
