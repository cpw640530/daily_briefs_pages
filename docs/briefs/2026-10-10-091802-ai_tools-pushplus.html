  • 编程场景：优先试用 miniClaudeCode。如果目标是理解代码 Agent 的任务循环、工具调用和权限设计，可先在本地测试项目中运行，并用 Git 分支隔离自动修改。

  • 创作场景：优先试用 ai-design-skills。将品牌色、字体、组件和响应式规则写入项目约束，再让 Cursor、Claude Code 或 Windsurf 生成页面，可以更快形成可复用的界面生产流程。
