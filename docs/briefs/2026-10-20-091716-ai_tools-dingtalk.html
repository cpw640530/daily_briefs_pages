1. 今日推荐结论

今天推荐 SINet、HTCUT 和 Vibe Shipped Agent，分别适合希望连接 AI Agent 与生产力工具的开发者、想用 Claude Code 操作视频编辑器的创作者，以及需要在多个 AI 编程环境中复用 MCP 工作流的开发者；三者均为新项目，Stars 尚未达到 1,000，但近期仍有提交记录。

工具二：HTCUT

  • 一句话介绍：面向 Mac 视频编辑器的 Vibe Editing 工具，通过 Claude Code 用自然语言驱动真实视频编辑操作。
  • 分类：Vibe Coding / 设计 / 创作工具
  • 适合谁：使用 macOS 视频编辑器、希望用 Claude Code 自动执行剪辑操作的视频创作者和技术型剪辑师。
  • 典型场景：用自然语言描述剪辑意图，由 Claude Code 在真实 Mac 视频编辑器中执行编辑任务、调整素材或生成编辑流程。
  • 核心功能：
  • Claude Code 插件
  • 面向真实 Mac 视频编辑器的编辑控制
  • 以“描述风格和意图”的方式进行视频编辑
  • 提供 Releases、Issues 和 Discussions，便于跟踪早期项目进展

5. 今日选择建议

  • 编程场景：优先试用 Vibe Shipped Agent，先接入一个客户端和只读 MCP 能力，再逐步开放代码修改和命令执行权限；如果关注 AI 原生 CLI 与多 Agent 协作，可观察 SINet 的后续提交。
  • 办公场景：三款工具都不是成熟的通用办公软件；若需要跨工具自动化，可将 Vibe Shipped Agent 作为实验性 MCP 工作流入口，但应先核实服务端、模型费用和数据权限。
  • 创作场景：视频创作者可在 macOS 测试 HTCUT，建议使用副本素材和可回滚项目，先验证简单剪切、素材定位和导出，不要直接处理唯一原始工程。
