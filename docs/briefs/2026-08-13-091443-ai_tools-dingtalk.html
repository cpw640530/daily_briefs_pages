AI工具日报｜2026-08-13

1. 今日推荐结论

今天推荐 Kobiton Automate、Paperr 和 Claude Codex Usage：分别适合需要用编码 Agent 执行移动端测试、希望私有部署个人与团队工作台，以及需要监控 Claude Code/Codex CLI 用量的用户；受限于候选资料，本期三者均按“新项目”收录。

2. 推荐工具

工具一：Kobiton Automate（新项目）

  • 一句话介绍：连接 Claude Code、Codex CLI、Copilot CLI、Cursor CLI 和 Gemini CLI 的移动应用测试自动化插件。
  • 分类：Vibe Coding / 自动化 / 编程插件
  • 适合谁：Android、iOS 开发者，移动测试工程师，以及已使用编码 Agent 的研发团队。
  • 典型场景：在编码工作区中管理测试设备、上传 App、运行移动端自动化测试并查看结果。
  • 核心功能：对接 Kobiton 移动测试平台；支持设备管理、应用上传、自动化测试和结果查询；兼容多种主流编码 Agent/CLI。
  • GitHub Stars：12（GitHub 搜索结果，2026-08-12）
  • 近期新增 Stars：资料未确认。
  • 最近更新时间：2026-08-12 10:57 UTC 有代码推送。
  • 最新版本：资料未确认。
  • 开源协议：MIT License。
  • 支持平台：Claude Code、GitHub Copilot CLI、Gemini CLI Extension、Cursor CLI、Codex CLI；移动测试覆盖 Android/iOS，具体运行环境要求资料未确认。
  • 使用成本：插件代码开源；Kobiton 平台服务价格资料未确认。
  • 上手步骤：进入仓库查看对应 Agent/CLI 的安装说明，配置 Kobiton 账户与访问凭据，连接测试设备，上传应用后从编码工作区发起测试任务。
  • 推荐理由：把移动测试能力直接带入 Vibe Coding 工作流，减少在 IDE、终端与设备云控制台之间切换；虽然 Stars 较低，但项目在 2026-08-12 仍有推送，且覆盖多个主流编码 Agent，因而作为活跃垂直工具入选。
  • 局限与风险：仅有 12 Stars，社区验证有限；依赖第三方设备云与账户权限；上传未发布 App 前应核查代码、构建产物及测试数据的安全策略。
  • 官网/仓库链接：GitHub｜Kobiton

  • 适合谁：重视数据私有化的个人、家庭、小团队，以及希望用一个系统管理日常工作的人。
  • 典型场景：统一管理任务、项目、日历、笔记、例行事务和专注工作，并通过内置 AI 助手与 Agent 辅助执行。
  • 核心功能：任务与项目管理、日历、笔记、例行事务、专注工具、共享墙式仪表盘、内置 AI 助手和 Agent。

  • 推荐理由：覆盖办公效率、知识管理和自动化三个方向，自托管模式有利于控制数据边界；因近期仍有代码活动且功能组合具有实用性，在缺少 1,000 Stars 以上新候选的情况下补充入选。
