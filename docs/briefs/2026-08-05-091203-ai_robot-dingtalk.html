2. 今日三大事件

事件一：美国扩大受限设备范围，境外移动机器人面临市场准入风险 ★

  • 发生了什么：据 IEEE Spectrum 报道，美国 FCC 于 2026 年 7 月 28 日将重量超过 2 千克、具备通信能力的移动机器人纳入“Covered List”。报道指出，这意味着相关类别的外国新产品将不再具备进入美国市场所需的设备授权资格。
  • 技术变化：本次不是机器人算法或硬件升级，而是监管边界从传统通信设备扩大到具备联网、感知和移动能力的机器人平台。
  • 为什么重要：FCC 设备授权是大量无线联网产品进入美国市场的重要前置条件。若规则按报道口径执行，境外机器人企业可能需要重新设计通信模块、调整供应链或寻求本地化生产。
  • 产业影响：仓储、巡检、配送、安防及部分人形机器人厂商的美国市场拓展成本可能上升；美国本土整机、通信组件和系统集成商可能受益。具体覆盖国家、存量产品处理方式及豁免机制仍需以 FCC 文件为准。
  • 接下来关注：FCC 对“mobile robots”“communicating”的正式定义、既有型号是否受影响、企业申诉与豁免程序，以及美国盟友产品是否同样受到限制。
  • 来源/时间：IEEE Spectrum｜What Robotics Companies Think About the U.S. Foreign Robot Ban｜2026-08-04

事件二：OpenAI 引入第三方网络安全评估，模型安全验证进一步外部化

  • 发生了什么：OpenAI 于 2026 年 8 月 4 日发布“涉及 OpenAI 模型的第三方网络安全评估”。现有资料仅确认公告标题与发布时间，评估机构、测试模型、攻击场景及结果未提供，详细结论资料未确认。
  • 技术变化：没有可靠资料证明模型、API 或安全过滤机制同步更新；可确认的变化是 OpenAI 对外披露了第三方网络安全评估事项。
  • 为什么重要：外部评估有助于降低模型厂商自行测试带来的利益冲突，也是企业和政府客户判断模型是否适合高风险网络安全场景的重要依据。
  • 产业影响：若 OpenAI后续披露统一测试方法和可复现结果，可能推动前沿模型供应商采用更标准化的网络能力分级、红队测试和事件报告机制。
  • 接下来关注：第三方机构的独立性、评估是否覆盖自主代理和工具调用、漏洞披露规则，以及测试结果是否影响 API 权限和企业采购要求。
  • 来源/时间：OpenAI｜Third-party cyber evaluations involving OpenAI models｜2026-08-04

事件三：Google DeepMind 发布 Gemini Robotics 2，机器人模型转向全身协同

  • 发生了什么：Google DeepMind 官网列出“Gemini Robotics 2 brings whole body intelligence to robots”，表明其机器人模型升级方向已从局部操作扩展至全身智能。官方页面仅标注 2026 年 7 月，具体发布日期资料未确认。
  • 技术变化：根据官方标题，可确认的重点是“whole body intelligence”；具体模型规模、训练数据、支持硬件、基准成绩及 API 能力资料未确认。
  • 为什么重要：全身协调是人形机器人从固定工位操作走向移动、搬运和复杂环境作业的关键能力，也是视觉语言模型转化为物理行动能力的主要技术瓶颈。
  • 产业影响：若模型能够跨机器人本体迁移，机器人厂商的竞争重点可能由单一动作控制转向数据质量、整机适配、仿真训练和安全执行系统。
  • 接下来关注：是否开放 API 或模型权重、支持哪些机器人平台、长时序任务成功率，以及与 Gemini Robotics ER 2 的任务编排和多机器人协作能力如何组合。
