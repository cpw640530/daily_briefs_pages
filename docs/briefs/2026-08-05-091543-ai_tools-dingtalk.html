  • 典型场景：整理文件、提取文档信息、生成报告、编写 Shell 命令，以及将自然语言需求转化为可复用脚本。

  • 适合谁：希望在本地桌面环境试验 MCP、任务分解和多 Agent 协作的开发者与技术团队。
  • 典型场景：把复杂任务拆给多个子 Agent、连接 MCP 工具、建立个人桌面自动化入口，以及验证 Agent 编排方案。
