  • 核心功能：Markdown 编辑、DataTable、WhiteBoard、可调用工具的 AI Agent、浏览器调研、可视化工作流（依仓库描述）。

工具二：agentic-stock-contributor（新项目）

  • 一句话介绍：面向 Adobe Stock 投稿者的 Agent 优先工具包，包含 MCP server、Chrome 扩展，以及给 Claude Code / Codex / Cursor / Antigravity 用的 skill 与 playbook，最终提交动作仍由人手动点击。
  • 分类：Vibe Coding / 自动化（MCP + Skill）
  • 适合谁：用 Claude Code、Codex、Cursor、Antigravity 做工作流自动化，或需要把"网页后台操作"交给 Agent 的开发者；Adobe Stock 内容投稿者可直接上手。
  • 典型场景：让编码 Agent 通过 MCP 接管素材整理、元数据填写、批量上传等重复网页操作，人只在最后一步确认 Submit。
  • 核心功能：MCP server（工具暴露给 Agent）、Chrome 扩展（浏览器侧执行）、面向 Claude Code / Codex / Cursor / Antigravity 的 skill 与 playbook。

  • 近期新增 Stars：资料未确认
  • 最近更新时间：资料未确认；仓库出现在 2026-10-09 之后的检索结果中，且仓库 ID 显示为近期新建
  • 最新版本：资料未确认
  • 开源协议：资料未确认
  • 支持平台：Chrome 扩展 + MCP 兼容客户端（Claude Code、Codex、Cursor、Antigravity）
  • 使用成本：工具本身开源（协议未确认）；调用模型费用取决于你所用的 Agent 客户端
  • 上手步骤：克隆仓库 → 按 README 启动 MCP server → 安装 Chrome 扩展并登录目标站点 → 把仓库提供的 skill/playbook 放入 Claude Code、Codex 或 Cursor 的技能目录 → 用自然语言下达任务，人工确认提交。
  • 推荐理由：它是难得把"MCP server + 浏览器扩展 + Agent skill"三层串成完整链路的公开范例，且刻意保留"人工点击提交"的安全闸门；即使你不投稿素材，也可以把它当作自己业务后台自动化的模板。

  • 官网/仓库链接：https://github.com/Grunte12/agentic-stock-contributor

工具三：ENZO（持续更新）

  • 一句话介绍：自托管 AI 工作区，内置 Agent、技能与 Gmail / Calendar 等工具，全部运行在你自己的模型 API Key 上（BYOK）。
  • 分类：效率工具 / 自托管 AI 工作区
  • 适合谁：拥有自建服务器、在意数据不外流、愿意自带 Groq / OpenRouter / NVIDIA / Hugging Face / Google AI Key 的个人与小队。
  • 典型场景：把邮件分拣、日程整理、常规调研等任务交给自托管 Agent，在 Docker 环境中统一管理。
  • 核心功能：多 Agent 与技能系统、Gmail / Calendar 工具接入、MCP 支持、BYOK 多供应商模型路由、Docker 部署。
  • GitHub Stars：113
  • 近期新增 Stars：资料未确认
  • 最近更新时间：2026-10-16（UTC，仓库推送时间）
  • 最新版本：资料未确认
  • 开源协议：Apache License 2.0
  • 支持平台：Docker 自托管（Web 界面）；具体系统要求以仓库为准
  • 使用成本：软件免费；实际成本为你所选模型供应商的 API 费用
  • 上手步骤：克隆仓库 → 按 README 用 Docker 启动 → 在配置中填入自有模型 Key → 按需开启 Gmail / Calendar 工具授权 → 在工作区内创建第一个 Agent 任务。
  • 推荐理由：BYOK + 自托管的组合对数据敏感型团队实用，且仓库仍在高频推送。
  • 局限与风险：自托管需要运维能力；接入 Gmail / Calendar 意味着授予高敏感权限，需自行评估合规；Stars 规模仍小（113），生态与长期维护存在不确定性。
  • 官网/仓库链接：https://github.com/theguysudo/ENZO ，主页：https://enzo-hub.duckdns.org
