工具二：ClaudeCodeExtension（持续更新）

  • 一句话介绍：面向 Visual Studio .NET 的 AI 编程扩展，为 Claude Code、Codex、Cursor Agent、OpenCode 等工具提供统一交互界面。
  • 分类：编程插件 / Vibe Coding
  • 适合谁：主要使用 Visual Studio、尤其是 .NET/C# 技术栈，并需要频繁切换代码 Agent 的开发者。
  • 典型场景：让 Agent 修改项目、查看差异、粘贴图片或文件、追踪会话和用量。
  • 核心功能：AI 会话界面、图片/文件粘贴、Diff 查看、Agent 完成后的动作、用量跟踪、会话历史，并兼容多个代码 Agent。

  • 支持平台：Visual Studio .NET；同时提供Visual Studio Marketplace 扩展页。
  • 使用成本：扩展开源；Claude Code、Codex、Cursor Agent 等底层服务的订阅或 API 成本另计，具体价格资料未确认。
